# スクールライフ完全攻略

新入生にも在校生にも役立つ、生徒アンケートからつくる学校生活ガイドの骨組みです。

## 内容
- ホーム、先生図鑑と検索、5項目ランキング切替
- 部活動13種（運動部・文化部の絞り込み）、委員会10種と詳細ダイアログ
- 学校生活の本音・新入生への一言のカテゴリ切替
- スマホ対応、キーボード操作、実データのない状態の表示

架空の先生・得票・生徒の声は入れていません。部活動・委員会の名前だけを設定しています。

## 動かし方
`index.html`をブラウザで開くか、このフォルダで `python3 -m http.server 8000` を実行して http://localhost:8000 を開きます。ビルドやnpmインストールは不要です。

## データを更新する
`assets/data.js` の `SCHOOL_DATA` を編集します。先生のIDは重複しない固定値にします。votes は優しさ(kindness)、厳しさ(strictness)、面白さ(humor)、わかりやすさ(clarity)、熱血度(passion)の票数です。同点は同順位で表示します。得票が0の先生はランキングに表示しません。先生図鑑とランキングは別の見せ方です。

自由記述や名前はHTMLとして実行せずテキストとして表示します。公開確認済みの集計・要約だけを保存してください。原票・回答者の情報はこのリポジトリに入れないでください。新しいデータを入れた際は、集計の母数・期間・掲載基準も画面に追記してください。

## Cloudflare Pagesへ
GitHubにこのフォルダの中身を登録し、Cloudflare Pagesでそのリポジトリを連携します。
- フレームワーク：なし
- ビルドコマンド：空欄（画面が要求する場合は `exit 0`）
- 出力ディレクトリ：`.`（リポジトリのルート）
- 本番ブランチ：main（実際の既定ブランチに合わせる）

静的ファイルの直接アップロードでも利用できます。`.pages.dev`のURLはCloudflare側でプロジェクトを作成した後に決まります。本成果物は未デプロイです。

## 共有
GitHubのSettings → Collaboratorsで各人を招待して編集できます。パスワードを共有する必要はありません。現在のリポジトリは公開設定のため、登録したコードやデータは誰でも閲覧できます。非公開で管理したい場合は、リポジトリ所有者が公開設定を変更してください。

## 公開範囲
noindex/nofollow を設定していますが、URLを知っている第三者の閲覧や転載を防ぐ機能ではありません。公開前に学校と掲載内容を確認してください。
