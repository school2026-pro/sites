# スクールライフ完全攻略

岡山大学附属中学校の生徒による探究企画。アンケートから先生・部活・委員会・学校生活の本音を紹介します。

- 公開サイト：https://school2026-pro.github.io/sites/
- リポジトリ：https://github.com/school2026-pro/sites
- GitHub Pages：`main` のルートから公開。ビルド不要。

## 現在の内容

- 明るいミント・水色・クリーム色を使った、スマホ対応の静的サイト。
- 先生図鑑と5項目ランキングを同じコーナーに統合。旧 `#rankings` リンクも利用可能。
- 先生の検索、ランキングの項目切り替え、一覧・ランキングから詳細表示。
- 部活動13種・委員会10種の一覧と検索。部活は運動部／文化部で絞り込み。
- 部活診断・委員会診断：それぞれ5問、回答の見直し・再診断・結果から詳細表示。
- 生徒の声をカテゴリーで表示。

先生・票数・生徒の声の実データは未掲載です。部活・委員会の名称のみ設定し、説明や雰囲気は集計準備中と表示します。

## ファイル

| ファイル | 用途 |
| --- | --- |
| `index.html` | ヘッダー、メニュー、読み込み、フッター、ダイアログ |
| `assets/style.css` | 字体・配色・レスポンシブ表示 |
| `assets/app.js` | 画面描画、検索、ランキング、診断UI |
| `assets/quiz.js` | 診断の質問・分類・候補抽出 |
| `assets/data.js` | 公開確認済みの掲載データ |
| `assets/campus.svg` | オリジナルの学校生活イメージ（実際の校舎図ではない） |
| `assets/mark.svg` | オリジナルの本をモチーフにしたアイコン |

フレームワーク・npm・APIキーは不要。字体はGoogle FontsのNoto Sans JPとZen Maru Gothicを利用し、取得できない場合はシステムフォントを使用します。

## データ更新

`assets/data.js` の `window.SCHOOL_DATA` を編集。フォームとの自動同期やCSV取込機能はありません。

先生は重複しない固定IDを使います。

```js
{
  id: 'teacher-1', name: '先生名', subject: '教科',
  votes: {kindness:0, strictness:0, humor:0, clarity:0, passion:0},
  summary: '授業の特徴', tips: '授業を楽しむコツ', voices: []
}
```

5項目：優しさ、厳しさ、面白さ、わかりやすさ、熱血度。票数順に表示し、同票は同順位（1位・1位・3位）。0票はランキングに表示しません。総合順位や能力点数には換算しません。名前の表記統一・回答内の重複除外は原票集計時に行ってください。集計時には、フォームが順不同の最大3名方式か順位付き方式かを確認してください。

部活・委員会：`id`, `name`, `frequency`, `atmosphere: []`, `summary`, `voices: []`。部活には `category: '運動部' | '文化部'` を付けます。

学校生活の声：`{category:'新入生へ一言',text:'掲載文'}`。カテゴリーは「よかったこと」「大変なこと」「改善アイデア」「新入生へ一言」。`updatedAt` に更新日を入力してください。`satisfaction` は予約フィールドで、表示機能はありません。

掲載時は回答数・期間・掲載基準も画面に追記してください。文字列はHTMLとして実行せずエスケープして表示します。

## 診断の考え方

ブラウザ内のルールで候補を選びます。回答を外部へ送信・保存せず、生成AIや外部APIも使用しません。

- 部活：競技・活動の種類に応じた分類。最初に明確な分野を選んだ場合、その分野を優先します。
- 委員会：名称と一般的な活動分野をもとにした分類。
- 選んだ興味との重なりが多い候補を紹介。3件目と同点の候補も表示するため、3件を超えることがあります。興味が未定なら一覧への案内を表示します。
- 適性・性格・実際の活動量・雰囲気を断定するものではありません。実際の活動情報が集まったら質問と分類を見直してください。

## 共同編集・公開

所有者がGitHubのSettings → Collaboratorsから各自のアカウントを招待します。認証情報は共有しません。同時作業はブランチとPRで変更を確認してください。

`main` 更新後はActionsの「pages build and deployment」の成功と公開サイトを確認します。古いCSS／JSが残る場合は `index.html` の `?v=` を更新してください。

リポジトリもサイトも公開されています。原票・回答者を特定する情報・認証情報は登録しないでください。noindex/nofollowは閲覧制限ではありません。実際の結果は先生・学校と掲載内容を確認してから掲載する方針です。

## 探す楽しさの仕掛け

- 学校イラストのリンクから先生・部活・委員会へ移動。スマホではイラストの下に入口を表示。
- 先生特集の本を押すと5項目の切り口を一つずつ紹介。実在しない先生や票数は生成しません。
- 部活・委員会一覧の「ひとつ、おまかせで見る」は現在の検索条件内の活動を一つ紹介。適性診断とは別の機能です。
- 「気になる」で部活・委員会それぞれ3件までメモし、活動内容・頻度・雰囲気を比較。データ未掲載項目は集計準備中と表示。
- メモは `school-guide-interests-v1` キーでこのブラウザのlocalStorageに活動IDだけを保存。外部送信・名前・診断回答の保存なし。保存機能が使えない場合はメモリ内で動作します。
- `assets/features.js` がこれらの機能を担当。動きを減らす設定ではアニメーションを抑制します。
