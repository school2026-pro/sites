# 3D校内マップ・週間日課表の確認記録

2026年11月15日

## 再現の根拠

- 校舎の輪郭・配置：岡山大学「校舎改修Ⅰ機械設備工事」構内配置図（M-02、PDF29ページ）をトレース。
- 仮設校舎：仮設校舎設置工事の配置図（PDF23ページ）と学校の現行教室配置図を参照。
- 教室名・階構成：学校公式の工事期間中の校舎配置図。
- 日課：学校公式「本校の教育の特徴」の日課表画像。全曜日の午前を共通表示、午後は曜日ごとの差を保持。

3Dは配置を理解するための案内モデル。実測された外観モデルではなく、階高・外壁・細部は簡略化している。構内配置図は平面を基準とし、階別に展開された案内図を建物の敷地輪郭として扱っていない。

## 独立AIレビューと修正

初回の独立レビューで次の問題を発見し、修正後に同じレビュー担当が再確認した。

1. 「本文へ」リンクの同一画面移動でレンダラーが破棄される問題：同一画面アンカーは破棄対象から除外。
2. SVG再描画・ダイアログ終了時にキーボード選択位置を失う問題：建物キーでフォーカスを復元し、対象消失時は地図本体へ復帰。
3. 階ボタンの再生成でフォーカスを失う問題：同じ階の新しいボタンへ復帰。
4. モバイルで建物ラベルが重なる問題：上下左右の候補から非衝突位置を探索。画面外・配置不能なラベルを表示せず、建物一覧からもアクセス可能にした。
5. 狭い日課表でER時刻がはみ出す問題：開始・終了時刻を分けて改行し、終了の括弧表記を保持。

再レビューの検査範囲では、追加の修正必須事項は見つからなかった。

## 検証

- 独立担当の出力SVG数値検査：1,056場面。幅280/320/350/390px、最小・最大ズーム、低角度・標準・真上、360度回転の組み合わせで、ラベルの重なり・画面外はみ出しを検査。
- イベント検査：ズーム上下限、全体表示への復帰、ドラッグ・ピンチ終了時の誤タップ抑止。
- ブラウザ操作：建物選択、教室説明、週間表のER説明、ズーム上下限、キーボード回転、スキップリンク後の描画、ダイアログ終了後のフォーカス復帰。
- 320px幅の実iframe表示：日課表の全時刻要素で横方向のはみ出しなし。
- 日課表の時刻・水曜日の清掃→帰りの会→ER・木曜日16:45完全下校・午後のセル結合を確認。
